# ADR-001 — Marca oficial COS

- **Estado:** Aprobada
- **Fuente:** [MARCA_OFICIAL_V1.md](../gestion/MARCA_OFICIAL_V1.md)
- **Fecha de referencia:** V1

## Decisión

El producto se identifica oficialmente como **COS — Construction Operating System**.

## Contexto

La marca debe ser consistente en la documentación, la interfaz y los entregables del producto. La especificación completa de identidad, alcance y acta se conserva en el documento fuente.

## Consecuencias

- La documentación debe usar COS como identidad principal.
- Los documentos históricos de renombre se mantienen como antecedentes sustituidos.
- Las nuevas decisiones deben referirse al nombre oficial.
