# ADR-002 — APU como conocimiento reutilizable

- **Estado:** Aprobada para Fase 2B
- **Fuente:** [Diseño APU Fase 2B](../arquitectura/FASE2B_DISENO_APU.md)
- **Relación:** [Arquitectura de datos V1](../arquitectura/ARQUITECTURA_DATOS_V1.md)

## Decisión

El APU se modela como conocimiento técnico versionado y reutilizable, separado de su uso contextual dentro de un proyecto.

## Consecuencias

- Se distinguen el maestro APU, sus versiones y sus usos.
- La evolución debe conservar trazabilidad y compatibilidad histórica.
- El modelo puede alimentar presupuestos, comparaciones y capacidades futuras de inteligencia.
