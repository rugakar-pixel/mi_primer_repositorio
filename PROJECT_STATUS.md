# Estado del producto — COS

**Nombre oficial:** COS — Construction Operating System  
**Descriptor:** Gerente Administrativo IA para Construcción  
**Fecha de revisión de identidad:** 2026-11-06

## Resumen

COS evoluciona desde una herramienta de presupuesto de mano de obra y flujo de
caja hacia un sistema de gestión administrativa para construcción.

## Capacidades implementadas o presentes en el prototipo

- Empresas, directorio de usuarios y membresías.
- Proyectos y versiones con auditoría y persistencia de Mano de Obra.
- Estructura WBS por versión, con capítulos y partidas.
- Módulos de mano de obra, costos/APU, materiales de demostración y
  consolidación.
- Aplicación web React/TypeScript, API FastAPI y persistencia PostgreSQL para
  los flujos que ya están conectados.

La cobertura y persistencia dependen de cada módulo; los datos demo no deben
interpretarse como registros operativos persistidos.

## Visión y límites

La dirección de producto es un Gerente Administrativo IA para Construcción.
Inteligencia administrativa y análisis documental forman parte de la visión,
pero no deben describirse como capacidades disponibles hasta que exista una
implementación validada. El acceso actual es de demostración y no sustituye
autenticación ni autorización de producción.

## Identidad e historial

La marca vigente es **COS (Construction Operating System)**. El nombre
original, **Motor de Presupuesto MO y Flujo de Caja Nicaragua 2026**, se
conserva únicamente como contexto histórico. **ObraNexa** fue una propuesta
provisional sustituida por la decisión de Dirección del 2026-11-06.
